## 🚀 Project Overview

**SauceDemo Manual Testing** is a comprehensive web application testing project created to demonstrate practical **Software Quality Assurance (SQA)** and **Manual Testing** skills.

The project focuses on testing the functionality, usability, and reliability of the SauceDemo e-commerce web application.

The testing process follows standard QA practices including:

* 🔍 Requirement Analysis
* 📝 Test Scenario Creation
* 📋 Test Case Design
* 🐞 Bug Identification & Reporting
* ▶️ Test Execution
* 📊 Test Result Documentation
* 📸 Testing Evidence & Screenshots

---

# 🎯 Application Under Test

**Application:** SauceDemo
**Testing Type:** Manual Testing
**Application Type:** E-commerce Web Application

The application provides features such as:

* User Login
* Product Listing
* Product Sorting
* Shopping Cart
* Product Removal
* Checkout
* Order Completion

# 🧪 Testing Scope

The following modules were tested:

### 🔐 1. Login Testing

Tested:

* Valid login
* Invalid username
* Invalid password
* Empty username
* Empty password
* Error message validation

### 🛍️ 2. Product Testing

Tested:

* Product names
* Product descriptions
* Product prices
* Product images
* Product sorting
* Product availability

### 🛒 3. Cart Testing

Tested:

* Adding products
* Removing products
* Cart item count
* Cart product names
* Continue Shopping functionality

### 💳 4. Checkout Testing

Tested:

* Checkout navigation
* Customer information
* Postal code validation
* Checkout item verification
* Subtotal
* Tax
* Total amount
* Order completion
